# Экспериментальные блокноты

Этот каталог предназначен для основных эмпирических блокнотов.

Запланированные блокноты:

1. `01_synthetic_noise.ipynb` — контролируемые синтетические временные ряды с известными ограничениями.
2. `02_household_power.ipynb` — ограничения для бытового потребления электроэнергии.
3. `03_m5_sales.ipynb` — иерархия розничных продаж и ограничения на доли.
4. `04_lobster_bid_ask.ipynb` — ограничения цен покупки/продажи и книги лимитных заявок.
5. `05_lobster_backtest.ipynb` — прогнозирование LOBSTER с учётом издержек и бэктест торговой стратегии.
6. `06_summary.ipynb` — сравнение наборов данных с помощью тестов Фридмана и Неменьи.

Блокнот для воспроизведения оригинальной статьи хранится отдельно в
`simulations/`.
