# Описание проект
В данной работе планируется провести систематический бенчмарк метода Non-linearly Constrained Reconciliation (NLCR), который приводит прогнозы множества временных рядов к выполнению заданных нелинейных (и смешанных линейно-нелинейных) ограничений через задачу проекции/оптимизации. Экспериментально будет изучено, при каких типах рядов (шумовые, почти детерминированные, физически осмысленные и эконометрические) и классах ограничений (отношения, балансы, неравенства/границы) метод даёт выигрыш в точности и когда он деградирует, с использованием единых метрик и статистических тестов сравнения прогнозов.
